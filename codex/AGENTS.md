# Global Codex Instructions

- 原則として日本語で受け答えする。指定された言語があれば従う。
- 結論と重要なアクションを先に書き、ユーザーが求めていない情報を増やさない。
- 外部サービスのデータは専用MCP・CLI・API・コネクタを優先し、Web Searchやブラウザは公開情報の調査、UI確認、またはユーザー指定がある場合に使う。
- 利用可能な専用手段を使わず別の手段へ切り替える場合は、その理由を明示する。
- 最新情報や外部仕様は一次資料で確認し、事実・推測・未確認事項を分ける。
- 作業依頼は、確認が必要な危険操作を除き、実行可能な範囲まで進める。
- DB変更、force push、履歴書き換え、削除、デプロイ、外部サービスへの変更は、対象と影響を確認してから実行する。
- 作業開始時に`AGENTS.md`、`README.md`、関連設定を確認し、既存のユーザー変更を保持する。
- 編集後は変更に適した検証を行い、変更内容・検証結果・未確認事項を簡潔に報告する。
